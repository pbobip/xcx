# Triage Labels

工程技能使用以下五种固定角色。右侧为本仓库实际使用的 GitHub 标签。

| 工程角色 | GitHub 标签 | 含义 |
|---|---|---|
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待需求方补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求完整，可由 Codex 独立实施 |
| `ready-for-human` | `ready-for-human` | 需要人工实施或外部操作 |
| `wontfix` | `wontfix` | 已决定不处理 |

当技能提到某种角色时，必须使用本表对应的标签，不创建含义重复的标签。
