# Domain Docs

本项目采用单一上下文，所有小程序页面、云函数和 Web 运营后台共享同一套领域术语与架构决策。

## 开发前读取

- 根目录 `CONTEXT.md`：项目术语、业务规则和明确排除的同义词；
- `docs/adr/`：与当前任务相关的架构决策记录；
- `docs/prd/`：当前经确认的产品需求文档。

文件尚不存在时可以继续，不需要为了占位提前创建空文件。术语或重要决策真正确定后，再通过领域建模流程补充。

## 使用统一术语

任务标题、测试名称、接口动作和代码命名应使用 `CONTEXT.md` 中定义的术语。不得在“套餐、订单、履约、派单、支付、退款、投诉”等核心概念上随意换用近义词。

## 处理决策冲突

如果新方案与现有 ADR 冲突，必须明确指出冲突并重新评审，不得静默覆盖历史决策。
